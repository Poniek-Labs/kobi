Kobi was originally developped by Codebunny100 as a lightweight, simple alternative to other
editors like VIM or NANO, When Codebunny100 and Poniek Labs started working on a Linux Distro,
Kobi was re-written as a more modern, efficient editor, streamlined for Poniek Labs' Upcoming Linux Distro.
